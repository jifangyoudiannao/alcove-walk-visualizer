    使用 Alcove Studio

    黄色三角形是 fundamental alcove A₀，三条不同颜色的边是 s₀ / s₁ / s₂ 型墙。点击当前 alcove 共边的浅绿色三角形即可增加一步。路线保留回走和重复经过的 alcove。

    滚轮围绕光标位置缩放；按住空格拖动画布，或切换到手掌模式。Ctrl/⌘+Z 撤销，Ctrl/⌘+Shift+Z 重做。

    输入反射字采用 右乘 约定：从 A₀ 开始，每次穿越标记为 sᵢ 的墙，终点由 w ↦ wsᵢ 确定。

    Weight 与折叠：输入 λ = aω₁ + bω₂，得到从 A₀ 到 A₀ − λ 的一条 reduced path。折叠会触及当前墙并返回同一个 alcove；后续步骤仍按原墙类型序列，在当前 alcove 寻找下一面墙。折叠路径不必结束于 A₀ − λ。

    独立 Ram 模式：参考终点使用 A₀ + λ，起点可选择有限 Weyl 群的任意 wA₀。固定参考路径后，每一步高亮实际墙并显示合法 crossing / folding 选择，也可枚举全部合法路径。自由绘制区域原有 A₀ − λ 工具保持不变。

    规则区别：“每墙均可折叠”允许所有穿墙 / 折叠选择；“仅正折叠”要求折叠留在墙的正侧。Ram §3.2 的 Theorem 3.3 要求第 k 步的折叠符号等于参考穿墙符号 εₖ；以 A₀ 为起点（w = e）并使用同一参考路径时，只有原始不折叠路径满足该条件。这里没有加入 Lenart–Postnikov 的 Bruhat cover 条件。

    折叠定义与带符号规则：Arun Ram, §3.1–3.2，Theorem 3.3。

    参照：affineNotes.pdf，第 75 页，以及第 19 页 Example 2.19。
